# Macdows release notes

## 1.35 build 75 · 2026-11-24

- Choose **Settings…** from the menu bar to open one window. Its five panes are Switcher, Windows, Keyboard, Apps & Finder, and General. Settings stay visible when unavailable.
- **Windows** now has one red-button choice. Close the window, quit after the last window closes, or quit when closing any window. The option to keep menu-bar and background apps running applies to both quit modes.
- **Switcher** groups ⌘Tab mode, appearance, Finder filtering and Screen Recording access. **Windows** groups window cycling and desktop switching with window controls. **Keyboard** groups Globe/Fn and keyboard layout shortcuts.

## 1.35 build 74 · 2026-11-24

- Menu sections use distinct headings so unavailable commands are easier to spot. All settings remain within one submenu.
- On macOS 11–14, the status and keyboard handler now ignore tiling shortcuts that require macOS 15.

## 1.35 build 73 · 2026-11-24

- Pick the ⌘Tab switcher and desktop scope in one step. Choose macOS for all apps, or Macdows for this desktop or all desktops.
- The menu has one level of submenus. Dependent settings stay in place and appear dimmed until available. Red-click exceptions sit under the quit setting, and preview access appears beside the display options.
- Macdows checks Screen Recording access on startup when previews are selected and detects permission changes. Existing preview preferences carry forward on update.

## 1.35 build 70 · 2026-11-24

- Browse individual windows with titled previews. Nearby previews are preloaded and the panel shows how many items are outside the visible area.
- In the Macdows switcher, ⌘W closes the selected window and ⌘Q quits its app. For Finder, ⌘Q closes its windows.
