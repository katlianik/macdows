The shortcuts
you missed.

Open a menu-bar section to see its shortcuts and available options.

⌃← / →

Move & resize one window

Control+Left/Right places the active window on either half of the desktop at full working height, using macOS Move & Resize. Disable this option to keep the standard Space-switching shortcuts.

⌃ ⌥← / → / ↑ / ↓

Arrange two. Fill. Restore.

Control+Option+Left/Right arranges the active window and a second eligible window side by side. macOS chooses the second window. Up fills the desktop; Down restores the saved size using the same memory as the green button. If a large window has no useful smaller size to restore, Down or the green button makes it 80% of the desktop width and height. Repeated presses keep the size stable. It does not restore the pair together.

These two independent options require macOS 15+. Left/Right requires native tiling support and follows macOS tiling margins and application minimum sizes. Up and the green button use native Fill on macOS 15+. Down restores the size saved before the placement sequence and centers the window using its actual accepted size. Native commands run without opening menus, using system App Shortcuts installed by Macdows. Reopen other apps after installing this update so they load the shortcuts. New actions replace pending actions; no delayed resize retries run in the background. All actions respect window size limits.

⌘`

Cycle windows in any layout

Command+the physical grave key cycles through the current app’s standard, non-minimized windows, wrapping from last to first. Add Shift to go backwards. The active keyboard layout does not change the shortcut; it uses the physical key above Tab on standard Mac keyboards.

⌘Tab

Stay on this desktop

In ⌘Tab Switcher, choose macOS for all apps, or Macdows for this desktop or all desktops. Choose app icons, one preview per app, or one per window. Previews require Screen Recording permission. Hide Finder when it has no windows. Preview caching and preloading keep browsing smooth, and edge counts show how many items remain. Command-W closes the selected window; Command-Q quits its app, or closes all Finder windows. Disabled by default.

⌃ ⇧ ⌥← / →

Switch desktops

Press Control+Shift+Option+Left/Right, then release the keys to switch to the adjacent macOS desktop. Globe/Fn also works in place of Control when Macdows maps Globe/Fn to Control.

🌐 Globe+Shift

Globe+Shift. Switch languages.

Switch keyboard layouts with Globe+Shift. Keep the familiar two-key habit on your Mac. Globe-Space is a separately switchable alternative.

Red means quit

Quit an app with its red button. Quitting only on the last window starts enabled. Finder keeps its standard close behavior. Declared background apps and apps exposing their own menu-bar icon close normally and keep running; this protection is enabled by default and can be switched off.

Green means more room

Maximize to the usable desktop, with the menu bar still in view. Click again to restore the previous size.

Cut. Paste. Moved.

Cut files with ⌘X and move them with ⌘V. Finder handles the destination, name conflicts and undo. Your files stay at the source until you paste.

Make yourself
at home.

Install once. Pick your preferences.

  1. Move Macdows into Applications.

    Open the DMG and drag Macdows onto the Applications shortcut. Quit an earlier copy before updating.

  2. Open Macdows.

    Macdows is signed by Astonio Ltd and notarized by Apple. Open it from Applications and confirm the standard first-launch prompt if shown.

  3. Allow window and keyboard controls.

    Open General → Accessibility Settings in Macdows and enable the installed app under Privacy & Security → Accessibility, or Device Control and Data Access on newer macOS. Reopen Macdows. Allow Automation access to Finder for the empty-Finder feature and to System Events for desktop switching when prompted.

Before you install

What is Macdows?

Macdows is a free menu-bar utility for macOS by Astonio Ltd. It brings familiar Windows-style window actions and keyboard habits to a Mac.

Is Macdows completely free?

Yes. Macdows is free forever, with no subscriptions or hidden fees.

How do I switch keyboard languages?

Enable Globe-Shift in Globe Key & Language, then press and release Globe+Shift. Globe-Space is a separate alternative. Choose your keyboard layouts in macOS Text Input settings. In the default Globe-to-Option mode, Option+Shift also switches layouts.

What do the red and green buttons do?

The red button quits the app, with quit-only-on-last-window enabled by default. Finder keeps its standard close behavior. Declared background apps and apps exposing their own menu-bar icon close normally and keep running; this protection is enabled by default and can be switched off. The green button uses native Fill on macOS 15+ and restores the size saved before the placement sequence and centers the window when clicked again. Earlier macOS versions use direct resizing. Manually changing the window starts a new placement sequence. An initially large window without a useful smaller restore size is centered at 80% of the desktop width and height.

How do cut and paste work in Finder?

Press Command-X on selected files, open the destination in Finder and press Command-V. Macdows invokes Finder’s native move command. The files stay at their source until the move is performed. Finder handles name conflicts and undo.

Which Macs does Macdows support?

Macdows 1.35 supports Apple silicon and Intel Macs running macOS 11 or later. Launch at Login is available on macOS 13 and later. The native arrow shortcuts require macOS 15 or later.

How do I install Macdows?

Download Macdows.dmg, quit an older copy, drag Macdows.app into Applications and open it there. Enable its Accessibility or Device Control permission in macOS. Allow Automation access to Finder for the empty-Finder feature and to System Events for desktop switching when prompted.
